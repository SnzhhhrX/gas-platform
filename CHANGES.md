# GAS Geography — изменения этапа 1 (маскот, реакции, аудит)

## Сделано
- **Гас перерисован.** Тот же глобус с ростком, но взрослее: небольшие тёмные глаза, выразительные брови и рот, без румянца и ботинок, плоские формы в языке сайта. API `<Mascot mood size anim />` не менялся, все старые места работают.
- **8 настроений:** happy, cheer, wow, think, wave, oops, proud, sleep. Моргание, покачивание ростка, подпрыгивание и взмах руки включены, при `prefers-reduced-motion` всё отключается.
- **Реакции в уроке:** верный ответ, ошибка (слова поддержки, после двух ошибок подряд напоминание о подсказке), итог урока по звёздам. Тексты в `src/lib/gas.js`, фразы детерминированы.
- **Приветствие на «Пути»** по времени суток и серии (`GasSays`).
- **Исправлено:** повторяющийся `id` у `clipPath` при нескольких маскотах на странице.
- **Аудит контента:** `npm run audit` (`scripts/audit-content.mjs`).

## Результаты аудита (956 вопросов)
- Без иллюстрации 870 (91%). Типы: 625 выбор, 122 верно/неверно, 131 ввод, 76 карта, 2 multi.
- Столицы и «чей флаг» занимают около 20% вопросов, 75 вопросов начинаются «Какой город —».
- Пояснения: в среднем 37 символов, 796 короче 50.
- Верный вариант самый длинный в 55% вопросов (случайно было бы около 33%): ученик может угадывать по длине.
- Порядок вариантов перемешивается в рантайме (`vary.js`), перекоса позиции нет.

## Не сделано

- Климатограммы и тематические карты: нужны проверенные данные; по памяти и из разнородных источников я их не вставлял.
- Новые типы заданий (порядок, сопоставление, анализ графика), переписывание коротких пояснений, выравнивание длины вариантов.
- Остальной UI: карточки модулей, прогресс, пустые состояния и достижения с Гасом.
- **Не проверено:** `npm run build` и живой интерфейс (в среде без сети нет зависимостей). Выполните `npm ci && npm run build`.

# Этап 5 — навбар, рейтинг без моргания, профиль, загрузка с Гасом

# Этап 11 — реальная адаптация: исправление плана и интервальное повторение
- **Исправлена ошибка:** диагностика сохраняла план версии 4, а `planOf` принимал только версию 2, поэтому персональный порядок модулей, режимы «ускоренно/полный курс» и цель никогда не применялись. Теперь принимается версия ≥ 2 со структурой плана; повреждённый план заменяется планом по умолчанию. У пользователей с уже сохранённой диагностикой путь пересоберётся по их плану.
- **Интервальное повторение** (`lib/srs.js`, система Лейтнера): для каждого вопроса хранится ящик 0–5, срок повтора, число ответов и ошибок, навык. Интервалы 1, 2, 4, 8, 16, 35 дней. Верный ответ до срока ящик не двигает (зубрёжкой освоение не накрутить), ошибка возвращает вопрос на завтра. Вопросы с карты в повторение не входят. Записей не больше 700 (состояние синхронизируется с сервером, лимит 250 КБ); сервер новое поле `srs` пропускает без изменений.
- **Запись результатов:** `finishLesson` отмечает каждый заданный вопрос как верный/неверный. Сессия повторения не считается пройденным уроком и не увеличивает счётчик уроков.
- **Экран «Путь»:** карточка «Повторение — N вопр. пора повторить» появляется только когда есть вопросы со сроком.
- **Адаптация:** если по навыку накоплено достаточно ответов (не меньше 6 вопросов) и они слабые (много ошибок или частые возвраты), «ускоренный» и «освоенный» режимы заменяются на полный курс с пояснением. При малом числе ответов вывод не делается и процент не показывается.
- **Проверки:** `npm test` теперь запускает `test-srs.mjs` (14 проверок алгоритма), `test-program.mjs` (12 проверок на реальных данных программы) и серверные тесты. Все проходят, `npm run check` тоже.
- **Не проверено:** `npm run build` и живой интерфейс (нет сети и зависимостей). Синтаксис изменённых файлов проверен разбором TypeScript; карточку «Повторение» и её стили нужно посмотреть на устройстве.

# Этап 12 — честная диагностика и пересмотр программы
- **Проблемы старой диагностики:** «освоение» показывалось в процентах (0.95, 0.7, 0.15 были жёсткими константами по 1–3 ответам); самооценка пользователя подменяла результат теста для непроверенных тем, и по ней материал пропускался; «не знаю» нигде не учитывалось; в банке был вопрос с неверной формулировкой (про «выход к двум океанам через соседей» у стран без выхода к морю) и спорный (крупнейшая агломерация: рейтинги ООН расходятся); у части вопросов верный вариант был заметно длиннее остальных.
- **Новый тест:** 8 навыков, до 3 вопросов на каждый (первый средний, второй сложнее после верного или проще после неверного, третий подтверждает). Всего до 24 вопросов, завершить можно после 8, но по непроверенным темам выводов не будет. Банк расширен (по 2+ вопроса на каждом уровне по каждому навыку), 3 вопроса заменены, у 5 выровнены варианты (верный вариант самый длинный в 23% вопросов, случайно было бы около 33%). При пересдаче выбираются другие вопросы.
- **Результат по навыкам** (`lib/diagnosis.js`): «Уверенно», «Основа есть», «Есть пробелы», «Пока не знакомо», «Данных мало», «Не проверяли» с числом верных ответов («2 из 3, не знаю: 1»). Общий процент убран. Общий уровень назначается только если есть минимум три навыка с достаточными данными, иначе «Уровень уточнится».
- **Пропуск материала только по основаниям:** «проверка вместо уроков» только при трёх верных; «ускоренно» только когда верны оба вопроса среднего уровня; по одному-двум ответам, без ответов и по самооценке ничего не пропускается. Даже «освоено» означает проверку на 8 вопросов, не сдали — вернём уроки.
- **Понятно, почему:** у каждой темы в маршруте указана причина с числом ответов; выделен блок «Что изучить в первую очередь».
- **Пересмотр по мере обучения:** на экране «Путь» ссылка «Мои навыки и программа» (`Skills.jsx`): состояние каждого навыка по диагностике и по урокам (слабые ответы в уроках понижают оценку, закреплённые вопросы повышают не выше «Основа есть», пропуск материала от этого не появляется), «Обновить программу» (доступна после 20 новых ответов в уроках, пройденные уроки сохраняются) и «Пройти диагностику заново» (другие вопросы, можно отменить).
- **Совместимость:** план версии 5 хранит сжатые ответы диагностики (`diag`) и состояния навыков (`skills`); старые планы читаются (`v ≥ 2`), для них пересмотр опирается на данные уроков. Серверная часть не менялась.
- **Проверки:** новый `test-diagnosis.mjs` (35 проверок: классификация, выбор вопросов, банк, план, пересмотр), `npm test` запускает все наборы, `npm run check` обновлён под новый банк.
- **Не проверено:** `npm run build` и живой интерфейс; экраны результата и «Мои навыки» нужно посмотреть на телефоне (стили `.pl-skill`, `.skills-sheet`).

# Этап 13 — обучение вместо набора тестов: структура урока и разбор ошибок
**Аудит уроков.** Из 956 вопросов 796 с пояснением короче 50 символов (среднее 37), 91% без иллюстраций, верный вариант самый длинный в 55%. Урок открывался одной фразой, а при ошибке показывалось только общее «почему»: ученик не видел, что именно выбрал и почему так не получается.

**Что сделано для всех уроков**
- После неверного ответа показываются «Вы выбрали», «Верно» и, если для вопроса написан разбор, «Почему не так». Общее пояснение подписано «Как правильно».
- В конце урока: «Исправить ошибки» (те же вопросы ещё раз, варианты в другом порядке; на счёт, XP, сердца и интервальное повторение не влияет) и раскрывающийся «Разбор ошибок» со своим ответом, верным ответом и пояснением. Задания на карте во второй подход не входят.
- Исправлена вёрстка: жирный текст в обратной связи больше не переносится на отдельную строку, панель обратной связи прокручивается.
- Данные уроков получили необязательные поля: `goal` (чему научится ученик), `cards[].example` (разобранный пример: условие, шаги, ответ), `miss` (разбор по каждому неверному варианту). Старые уроки работают без изменений.

**Два урока переписаны полностью:** «Часовые пояса: считаем» и «Масштаб: считаем» (цель → 5 карточек объяснения с 2–3 разобранными примерами → вопросы с разбором каждой типичной ошибки: вычли вместо сложения, потеряли нуль, приняли 1° за минуту и т. д.). Старый вопрос о количестве часовых поясов России получил разбор (протяжённость около 170° по долготе, 170° ÷ 15° ≈ 11).

**Проверки (`test-lessons.mjs`, 40+ проверок).** Арифметика каждого примера и каждого верного ответа пересчитывается независимым кодом. Для каждого неверного варианта проверяется, что он действительно получается из названной в разборе ошибки (например, 17:00 = 20 − 3, 01:00 = 20 + 5, 60 км = отброшены четыре нуля вместо пяти). Примеры не совпадают с проверочными вопросами.

**Диагностика, доработка:** уровень «Продвинутый» теперь только если уверенно знакомо не меньше половины проверенных тем и нет явных пробелов (раньше мог получить ученик с пробелами по двум темам).

**Чего пока нет (честно):** по новой методике оформлены только 2 урока из ~200. Остальные получают общую обратную связь и исправление ошибок, но без целей и разобранных примеров: писать их нужно по темам, с проверкой фактов, а не массово. Следующий кандидат — курс «Рельеф и недра» и «Климат» (причинно-следственные схемы).
Скриншоты экранов (диагностика, «Мои навыки», урок, разбор ошибок) сняты скриптом с настоящих компонентов и реального CSS; иконки взяты из набора Lucide через react-icons, карты не отрисованы.
