# 🌍 GAS (Geography. Adventure. Skills.)

GAS — это современное геймифицированное веб-приложение для изучения географии, вдохновленное интерактивными обучающими UX-патернами.

---

## 🛠 Технологический стек

- **Frontend**: React, Vite, JavaScript, CSS3
- **Backend**: Node.js, Express.js
- **Архитектура**: REST API, Local-First Sync

---
