# Дизайн GAS: короткие правила

Принцип: **минимализм**. Один экран — одна задача. Если без элемента экран остаётся понятным, элемента нет.

**Знак.** `Wordmark.jsx`: буквы G, A, S нарисованы одной линией с круглыми концами; в «A» вместо перекладины зелёная точка (метка на карте). Единственный цветной акцент. Размеры: загрузка 44, вход 40, шапки 24–28. Иконка приложения (`public/icon.svg`): белая «G» на зелёном квадрате, читается и в 16 px. Гас — маскот на загрузке, входе и в уроках.

**Иконки.** Набор Lucide, штрих 2,2, круглые концы, цвет только `currentColor`. Три размера: 14 (рядом с мелким текстом), 18 (кнопки, списки, навигация), 24 (акценты). Любой другой размер приводится к ближайшему в `Icon`. Активное состояние — цвет родителя. Цветная плитка (`Tile`) — только для тем и достижений. Эмодзи в интерфейсе не используются.

**Шрифт.** Одно семейство для всего: Manrope, запасной — системный. Файл шрифта в проект не включён (нужна сеть), поэтому без подключения шрифта используется системный.

**Экраны.** Заголовок, главное содержимое, одна основная кнопка. Пояснения — одной строкой. Подробности (разбор ошибок, навыки) спрятаны за вторым действием.
